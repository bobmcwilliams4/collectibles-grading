## GRADE CALCULATION FORMULA

```
FINAL_GRADE = BASE_GRADE - SUM(defect_penalties)

Where:
- BASE_GRADE = 10.0 (starting point)
- Round to nearest 0.5 on CGC scale
- Minimum grade = 0.5
```

### PENALTY STACKING RULES

1. Multiple same-type defects: Add penalties, max 1.5x single penalty
2. Different defect types: Add all penalties directly
3. Cumulative cap: Total penalties cannot exceed 9.5
4. Severity escalation: If 3+ minor defects in same area, treat as moderate

## CONFIDENCE SCORING

```
CONFIDENCE = 1.0 - (grade_variance / 2.0)
- High: > 0.85 (grades within 0.3)
- Medium: 0.70-0.85 (within 0.6)
- Low: < 0.70 (vary > 0.6)
```
